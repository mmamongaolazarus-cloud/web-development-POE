 Soccer-Zone — Part 2

## What this part contains
This is the Part 2 version of the Soccer-Zone website. It focuses on CSS styling and mobile responsiveness.

## Improvements made
- One external stylesheet is used by all five pages.
- The pages have a consistent colour, typography and layout.
- Product cards use a simple responsive grid.
- Forms and buttons have basic styling.
- Relative widths are used for the main content and images/elements.
- A media query below 960px changes the product layout for smaller screens.
- A second media query below 600px stacks the navigation and product cards for phones.
- The layout avoids horizontal scrolling on small screens.
- Broken CSS/image paths from the supplied starter files were corrected. The supplied ZIP did not contain the referenced image folder, so simple text/emoji product visuals are used instead of broken image links.

## Main files
- `index.html` — Home
- `about.html` — About Us
- `products.html` — Products
- `enquiry.html` — Order enquiry
- `contacts.html` — Contact
- `css/style.css` — External stylesheet

## Testing checklist
- Check every navigation link.
- Resize the browser below 960px and 600px.
- Confirm that the navigation and product cards fit without horizontal scrolling.
- Check the enquiry form fields.

# Soccer-Zone — WEDE5020 Part 1 Rectified Project

## Overview
Soccer-Zone is a proposed local online soccer-boot store website. It provides business information, a product catalogue, an enquiry/order form and contact details.

## Goals
- Create a professional online presence.
- Display soccer boots with descriptions and prices.
- Make product enquiries simple.
- Provide clear business and contact information.
- Demonstrate HTML5, CSS3 and JavaScript skills.

## Target audience
Soccer players, students, amateur and professional footballers, parents buying boots, and local customers.

## Pages
`index.html` Home | `about.html` About Us | `products.html` Soccer Boots | `enquiry.html` Order/Enquiry | `contacts.html` Contact.

## Technologies
HTML5, CSS3, Visual Studio Code, Git and GitHub.
