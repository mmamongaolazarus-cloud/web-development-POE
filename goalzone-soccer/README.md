# 1. Project Overview

SOCCER-ZONE is a website project for a soccer boot store. The website gives customers information about the business, displays soccer boots, allows customers to make an enquiry, and provides contact information.

The website is aimed at students, amateur and professional footballers, parents and local customers who are looking for soccer footwear.

The website is developed using HTML5, CSS3 and JavaScript. HTML is used for the page structure, CSS is used for the appearance and responsive layout, and JavaScript is included for website functionality.

The project was developed in stages. Part 1 focused on the planning, structure and basic website development. Part 2 builds on that work by adding more detailed product information, an enquiry form, contact information, a map and responsive styling.

# 3. Website Goals and Objectives

The main goal of SOCCER-ZONE is to create a simple and user-friendly online presence for a soccer boot store.

The objectives are to:

- Create an online presence for SOCCER-ZONE.
- Introduce customers to the business.
- Display soccer boots and their prices.
- Allow customers to make product enquiries.
- Provide clear contact information.
- Make the website easy to navigate.
- Present the products in a clear and attractive way.
- Make the website usable on different screen sizes.
- Use comments to explain important parts of the code.
- Keep the project organised using separate HTML, CSS, JavaScript and image files.

# 4. Key Features and Functionality

The completed website contains the following main features:

### Home Page

The Home page introduces SOCCER-ZONE and includes:

- The SOCCER-ZONE logo.
- A welcome section.
- A soccer boots introduction.
- A "How to Order" section.
- Links to the About Us and Soccer Boots pages.
- A Shop Now link.

### About Us Page

The About Us page explains:

- What SOCCER-ZONE is.
- The goal of the business.
- The customers the business aims to serve.

### Soccer Boots / Products Page

The products page displays different soccer boot categories, including:

- Speed Pro Boots.
- Elite Control Boots.
- Pro Strike Boots.

The page includes product images, descriptions, prices and Buy Now links.

The prices shown in the completed Part 2 project include:

- Speed Pro Boots – R899.
- Elite Control Boots – R1,199.
- Pro Strike Boots – R1,499.

The Buy Now links direct customers to the enquiry page.

### Order / Enquiry Page

The enquiry page contains a product enquiry form.

The form collects:

- Full name.
- Email address.
- Telephone number.
- Number of items.
- Event date.
- Soccer boot/product selection.

The product selection includes:

- Speed Pro-Boots.
- Elite Control-Boots.
- Pro Strike Boots.
- Power Flex Boots.

### Contact Page

The Contact page provides:

- Business hours information.
- Email address.
- Telephone number.
- Location information.
- An embedded Google Maps map showing Polokwane, South Africa.

### Navigation

The website uses a navigation menu on the main pages so visitors can move between:

- Home.
- About Us.
- Soccer Boots.
- Order/Enquire Here.
- Contact.

### Responsive Design

The CSS includes responsive design rules for:

- Desktop screens.
- Tablet screens.
- Mobile phones.

The navigation changes to a vertical layout on smaller screens, and the product layout changes from three columns to two columns and then one column on smaller screens.

### Styling

The website uses:

- A green soccer-related colour scheme.
- Styled headers and navigation.
- Product sections.
- Buttons.
- Form styling.
- Cards/sections with spacing and shadows.
- A footer.
- Responsive layouts.

### JavaScript

A JavaScript file is included in the project for website functionality. The current Part 2 JavaScript file contains a browser-console message and provides the JavaScript file structure for further functionality.

## 7.6 Part 2 Responsive Design

The completed CSS includes responsive breakpoints.

For tablet-sized screens:

- The product layout changes from three columns to two columns.
- The main content width is adjusted.

For mobile screens:

- The navigation changes to a vertical layout.
- Navigation links use the full available width.
- Products are displayed in one column.
- Content sections have smaller padding.
- The heading size is reduced.
